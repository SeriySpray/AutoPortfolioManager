# AutoPortfolioManager ⚡

**AutoPortfolioManager** — це квант-скринер акцій індексу **S&P 500** із адаптованою математичною моделлю коефіцієнта Шарпа (**SSQ-Sharpe**), розробленою спеціально для вимірювання інвестиційного ризику поодиноких акцій (Single-Stock Risk Profiling).

---

## 🔬 Математична модель SSQ-Sharpe

Класичний коефіцієнт Шарпа:
$$SR = \frac{\mathbb{E}[R_i - R_f]}{\sigma_i}$$

### Чому він дає хибні результати для окремої акції?
1. **Симетрія волатильності:** Штрафує актив за швидкий звітний ріст так само, як і за обвали.
2. **Гаусове припущення:** Ігнорує жирні хвости (куртозис) та лівосторонній ризик обвалів (асиметрію).
3. **Автокореляція:** Трендовість акцій занижує виміряну річну дисперсію (Andrew Lo, 2002).
4. **Просідання:** Не враховує глибину і час перебування капіталу «під водою».

### Адаптована формула (SSQ-Sharpe)

$$SSQ\text{-}SR = \frac{\text{CAGR} - R_f}{\sigma_{\text{down, Lo}} \cdot \Psi_{\text{tail}} \cdot \Phi_{\text{drawdown}}}$$

Де:
1. **$\sigma_{\text{down}}$ (Downside Semi-Deviation):** Волатильність виключно спадних днів нижче безризикової ставки $R_f$:
   $$\sigma_{\text{down}} = \sqrt{\frac{1}{T} \sum_{t=1}^T \min(0, \, R_t - R_f)^2} \times \sqrt{252}$$
2. **$\sigma_{\text{down, Lo}}$ (Корекція Ендрю Ло):** Враховує автокореляцію повернень перших 5 лагів ($\rho_k$):
   $$\sigma_{\text{down, Lo}} = \sigma_{\text{down}} \times \sqrt{1 + 2 \sum_{k=1}^m \left(1 - \frac{k}{252}\right)\rho_k}$$
3. **$\Psi_{\text{tail}}$ (Хвостовий штраф за Корнішем-Фішером):** Покарання за негативний скіюнес $S$ та надлишковий ексцес $K_{\text{ex}}$:
   $$\Psi_{\text{tail}} = \max\left(0.1, \; 1 - \frac{S}{6} + \frac{K_{\text{ex}}}{24}\right)$$
4. **$\Phi_{\text{drawdown}}$ (Штраф за Ulcer Index):** Квадратична глибина та тривалість історичних просідань:
   $$UI = \sqrt{\frac{1}{T}\sum_{t=1}^T \left(\frac{P_t - \max_{\tau \le t} P_\tau}{\max_{\tau \le t} P_\tau}\right)^2}, \quad \Phi_{\text{drawdown}} = 1 + 2 \cdot UI$$

## 🚀 Встановлення та запуск

### Вимоги:
* Python 3.9+
* Бібліотеки: `yfinance`, `pandas`, `numpy`, `scipy`, `rich`, `pyarrow`

### Запуск:
```bash
# Інтерактивний режим із вибором дій у терміналі
python main.py

# Показати ТОП-50 найкращих компаній
python main.py --top 50

# Детальний розбір конкретної акції (рентген усіх складових ризику)
python main.py --ticker NVDA

# Примусово очистити кеш та завантажити найсвіжішу історію заново
python main.py --refresh

# Експорт розрахунків усіх 500+ компаній у CSV
python main.py --export sp500_results.csv
```

## ⚡ Кешування (Apache Parquet)
* Усі щоденні історичні дані завантажуються за максимальний період (`period="max"`) та зберігаються у бінарному форматі `cache/sp500_max_data.parquet`.
* Первинне завантаження триває менше хвилини для всіх 503 активів, а наступні запуски зчитуються з локального диска **миттєво (< 1 секунди)**.
* Кеш можна будь-коли скинути натисканням пункту меню в терміналі або прапорцем `--refresh`.
